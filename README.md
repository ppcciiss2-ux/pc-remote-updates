# PC 리모트 업데이트

PC 리모트 Windows 앱과 Android 앱이 새 버전을 확인하는 곳입니다. 앱이 자동으로 읽으므로 평소에는 직접 받을 필요가 없습니다.

- `windows-update.json`, `android-update.json`: 최신 버전 정보 (버전, 내려받기 주소, SHA-256)
- 설치 파일과 APK: [Releases](https://github.com/ppcciiss2-ux/pc-remote-updates/releases)

처음 설치할 때만 Releases에서 받습니다. 그다음부터는 앱이 새 버전을 알려 주고, 받은 파일의 SHA-256이 맞을 때만 설치합니다.
